# UAV-X: Resilient BVIOS Swarm Challenge

## Project Overview

A software-based UAV swarm simulation developed for the
UAV-X: Resilient BVIOS Swarm Challenge.

The system aims to demonstrate resilient swarm operation through
autonomous task allocation, path planning, communication monitoring,
failure detection, and task reallocation.

## Core Features

- Multi-UAV simulation
- Autonomous task allocation
- Path planning
- UAV state monitoring
- UAV communication modelling
- Heartbeat-based failure detection
- UAV failure handling
- Communication failure handling
- Automatic task reallocation
- Mission completion metrics
- Simulation visualization
